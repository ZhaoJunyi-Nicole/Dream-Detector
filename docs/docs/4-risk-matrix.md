# Risk Mitigation & Technical Constraints

## Core Technical Risks

* **Highest Risk Feature:** AI Dream Image Generation

* **The Hazard:**
  1.AI image generation may be difficult to implement. The API may fail or take too much time to generate images.
  2.It may also have usage limits.

## The Pivot Strategy

If our primary implementation for this feature fails or takes too long, our backup plan is to:

1. Use a simpler image generation tool or service.
2. Use preset dream images as placeholders so users can still view images related to their dreams.
