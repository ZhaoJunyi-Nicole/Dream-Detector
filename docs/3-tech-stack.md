# Tech Stack & Hosting Strategy

## Defined Tech Stack

* `HTML / CSS`: Used for building the app's page structure and design.

* `JavaScript`: Used for adding interactive features, such as saving and viewing dream records.

* `Python`: Used for handling app logic and future AI features.

* `GitHub`: Used for storing the project files and managing code changes.

## Hosting & Deployment Strategy

The application will be hosted using GitHub Pages. 
It will allow users to access DreamLog through a web browser. 
GitHub Pages will be used for the basic website, while more advanced AI features may need additional services in the future.
